# Security policy

This repository is an educational demonstration and is not intended for production use. Do not submit real customer information, credentials, confidential business data, or private policy documents.

If you discover a security issue, do not publish secrets or personal data in a public issue. Contact the repository maintainer privately.

Before any deployment beyond localhost, implement and review authentication, authorization, rate limiting, input validation, secure secret management, log retention, privacy controls, and protections for `/add-document` and `/ws/chat`. The included PII masking and prompt-injection detection are incomplete demonstration controls.
